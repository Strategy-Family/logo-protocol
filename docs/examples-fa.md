# نمونه درخواست‌ها

این درخواست‌ها را می‌توانید همان‌طور که هست کپی کنید و فقط جای [قلاب‌ها] را با اطلاعات خودتان پر کنید. یادتان باشد که اول باید آدرس ریپو را در چت گذاشته باشید.

## ساختن لوگو از صفر
```
می‌خواهم برای برندم از صفر لوگو بسازی. بریف برندم ضمیمه است و رنگ‌های برندم این‌هاست: [رنگ‌ها]
```
اگر بریف ندارید هم اشکالی ندارد؛ خود هوش مصنوعی پنج سؤال کوتاه می‌پرسد و شروع می‌کند.

## نقد لوگو
```
این لوگوی فعلی من است. طبق پروتکل نقدش کن و بگو کدام اصلاح‌ها بیشترین اثر را دارند.
```

## بازطراحی و ارتقا
```
این لوگو را ارتقا بده. رنگ‌های برندم: [رنگ‌ها]. بهترین مسیر را خودت انتخاب کن و بگو چرا.
```

## نسخه‌های مختلف
```
از این لوگوی تأییدشده نسخه‌ی تک‌رنگ روشن و تیره، آیکون پروفایل و فاوآیکون بساز.
```

## تست در کاربرد واقعی
```
لوگوی من را در کاربردهای واقعی تست کن: آواتار کوچک، زمینه‌ی تیره و لیبل محصول.
```

## آماده‌سازی برای طراح
```
می‌خواهم این لوگو را برای وکتورسازی و ثبت برند به طراح بدهم. بریف طراح را برایم بنویس.
```

## یک نکته
اگر ابزار شما تصویر نمی‌سازد، نگران نباشید. پروتکل در این حالت به جای تصویر، پرامپت آماده تحویل می‌دهد تا آن را در هر ابزار تصویرساز دیگری استفاده کنید.
